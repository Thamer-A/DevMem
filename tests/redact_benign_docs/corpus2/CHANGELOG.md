# Changelog

## 3.0.0

- Fixed: the password field of the login form kept its value after a failed login (#1000).
- Changed: `api_key` is now read from `API_KEY_FILE`; the `token` option is deprecated.
- Added: `max_tokens` setting (default 4096); `token_count` in metrics.
- Security: secrets are no longer written to the debug log. Rotate any key that was logged before 3.0.0.
